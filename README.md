# PsiQuiz
Proiect de invatatare interactiva pentru studiul psihologiei

Proiectul transforma informatiile din suporturie de curs ale UTM si alte materiale academice in resurse structurate: mind maps si quiz-uri interactive pentru verificarea cunostintelor.

# Drepturile de autor
Proiectul este destinat utilizarii in scop educational si personal.

Materialele academice utilizate ca sursa apartin autorilor si detinatorior de drepturi de autor.

PsiQuiz nu inlocuieste materialele de curs sau bibliografia recomandata de UTM, ci reprezinta un instrument complementar de invatare.

# Utilizarea AI
In dezvoltare acestui proiect am folosit Claude (Anthropic) pentru generarea mind maps si quiz-urilor, pe baza materialelor de curs.
